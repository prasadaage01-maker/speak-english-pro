# Speak English Pro

Professional Flutter starter project for a bilingual Marathi + English English-learning app.

## Features
- Sky-blue modern UI
- Splash screen
- Onboarding
- Firebase mobile OTP login
- Home dashboard
- Lessons, grammar, vocabulary, quiz
- AI chat teacher
- Speaking practice scaffold
- Profile/settings
- Marathi + English language toggle
- Progress tracking scaffold

## Setup
1. Install Flutter 3.22+.
2. Run `flutter pub get`.
3. Connect Firebase and add `lib/firebase_options.dart` generated by FlutterFire CLI.
4. Update `lib/services/ai_service.dart` with your AI API key.
5. Run the app.

## Build APK
```bash
flutter build apk --release
```

## Notes
This project is structured to be production-ready, but Firebase and AI credentials must be configured for live use.
